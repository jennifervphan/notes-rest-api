# Notes REST API

A simple REST API for managing notes using Node.js, Express.js and in-memeory storage.

## Features
- **GET /notes** - get all notes
- **POST /notes** - add a new notes
- **DELETE /notes/:id** - delete a note

## Getting Started

### Prerequisites

- Node.js 18+
- yarn

### Installation

```bash
# Install dependencies
yarn install

# Start development server
yarn run dev

# Run tests
yarn run test

# Format and lint
yarn run format
```
